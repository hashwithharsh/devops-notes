# Devops Fundamentals Notes

**Author:** Harsh Yadav

I use this repo to connect software delivery, Agile, Linux basics and the DevOps toolchain.

I am keeping this as a long-term study/reference repo. The useful part for me is the combination of explanation, practical commands, small labs and the troubleshooting notes I tend to forget.

I don't expect every note to have exactly the same structure. I write more detail for topics that I actually need to revisit often.


## My placement reference

## What I want to be able to explain

I should be able to take a simple application and explain the path from a developer change to a running release.

If I can explain where Git, CI, Docker, infrastructure automation, deployment and monitoring fit in that flow, the individual tools make much more sense.

A tool is not the starting point. The delivery problem is.

## How I study this repo

I don't try to read this repository from top to bottom in one sitting.

I use it in this order:

```text
1. DevOps basics
      ↓
2. SDLC / Agile / delivery flow
      ↓
3. Linux fundamentals
      ↓
4. Git
      ↓
5. Docker
      ↓
6. CI/CD
      ↓
7. Ansible / Terraform
      ↓
8. Kubernetes / cloud
```

For a new topic, I first read the concept note, then run the practical example in a lab. After that I change one thing deliberately and see what breaks.

If I am revising for an interview, I normally skim the headings first and then open the practical/troubleshooting notes for the topics I am weak in.

The goal is not to memorize every line. I want to understand the flow well enough that I can explain why a tool is used and demonstrate a small practical example.
